# 我们的小金库

手机入口：https://chaojiabin.github.io/women-de-xiaojia/gold/

- 前端托管在 GitHub Pages，可添加到手机主屏幕。
- 云端记录使用现有「我们的小家」服务的独立 `/api/gold` 接口与独立数据库表，不修改家务积分。
- 余额、备注、称呼及撤销结果在打开时、返回前台时和每 5 秒同步。
- 接口是公开读写的；知道接口地址的人可查看或修改记录。
- 本机旧记录保留在原来的浏览器存储中，通过「导入本机旧记录」主动导入；相同记录 ID 不会重复累计，已撤销记录不会复活。
- 离线时可查看最后同步结果，新增及修改需要联网。
- 页面每分钟检查版本，也可点底部「检查更新」。iPhone 可能需要完全关闭桌面 App 后重新打开。

`backend/` 保存已经集成到云端 Worker 的金子 API 和对应数据库迁移源码。GitHub Pages 本身不执行后端代码。
